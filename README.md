# Algebra Mastery

A fun, gamified, interactive web app for learning algebra. Covers linear equations through more complex methods with XP, streaks, achievements, visual tools, and instant feedback.

**Perfect for sharing and publishing** — pure HTML/CSS/JS, no build step required.

## Features

- **Explain Steps button** on every practice problem — see a full, clear explanation of the method and how to arrive at the answer (no need to answer first)
- **Gamification**: Earn XP, level up, build answer streaks, and unlock achievements
- **Interactive Practice**: Randomly generated problems with celebratory feedback (confetti + sound)
- **Visual Balance Scale** for linear equations
- **Solvers & Grapher**: Step-by-step linear/quadratic solvers + canvas graphing tool
- **Topics**: Linear Equations, Systems, Quadratics, Polynomials & Factoring, Exponents & Radicals, Rational Expressions
- **Progress Tracking**: Saved locally in the browser
- **Achievements System**: Badges for streaks, levels, and topic mastery
- **Responsive Design**: Works on desktop and mobile
- Beautiful KaTeX math rendering

## How to Run Locally

1. Download and extract the files.
2. Open `index.html` in any modern browser.
3. Start practicing!

## Publishing / Sharing

This app is fully static and ready for free hosting:

### Option 1: GitHub Pages (Recommended)
1. Create a new public GitHub repository
2. Upload all files from this folder (index.html, styles.css, app.js, logo.jpg, README.md)
3. Go to Settings → Pages → Deploy from branch (main / root)
4. Your app will be live at `https://yourusername.github.io/repo-name`

### Option 2: Netlify / Vercel
1. Drag and drop the folder onto [Netlify Drop](https://app.netlify.com/drop) or connect a Git repo on Vercel
2. Instant live URL

### Option 3: Any Static Host
Upload the files to any web server or static hosting service.
